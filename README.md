# Ma tournée scolaire

Application web de gestion des tournées de transport scolaire (matin / soir) :
tournées, enfants et contacts, présences, navigation Google Maps étape par étape,
appels et SMS aux familles, historique et relevés PDF.

- Application : https://casadamien-alt.github.io/tournee/
- Les données ne sont **pas** dans ce dépôt : elles sont stockées dans le Google Drive
  du propriétaire, via `apps-script.gs`, et protégées par un code secret.
- Les photos des reçus de carburant sont rangées dans le dossier « Ma tournée – reçus »
  du même Google Drive (après mise à jour de `apps-script.gs`).
